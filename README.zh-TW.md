## 檔案結構

| 檔案 | 內容 | 常改嗎？ |
|---|---|---|
| `data.js` | 首頁內容（名字、社群帳號、手機、專案） | ◎ |
| `_posts/` | 部落格文章（1 篇 = 1 個檔案） | ◎ |
| `index.html` / `home.js` | 首頁骨架 | 偶爾 |
| `blog/index.html` | 文章列表頁 | 幾乎不改 |
| `_layouts/post.html` | 文章頁樣式 | 幾乎不改 |
| `style.css` / `common.js` | 設計和動畫（所有頁面共用） | 幾乎不改 |
| `i18n.js` | 多語言翻譯詞典（日文・English・简体中文・繁體中文・한국어） | 偶爾 |
| `posts.json` | 文章列表資料（自動產生，不要改） | × |
| `_config.yml` | 部落格設定 | × |

## 寫部落格的方法

1. 開啟 `_posts` 資料夾，選擇 **Add file → Create new file**
2. 檔名寫成 `年-月-日-英文標題.md`
   例：`2026-11-25-magic-v3-review.md`
   （英文部分會成為網址 → `/blog/2026/11/25/magic-v3-review/`）
3. 在開頭寫上下面這段，然後在下面用 Markdown 寫內文

```markdown
---
title: Magic V3 を3ヶ月使った感想
tags: [Honor, 折りたたみ, レビュー]
pinned: true        # 想放進推薦時才寫。不需要就整行刪掉
cover: /images/magic-v3.jpg   # 封面圖（可以沒有）
---

從這裡開始是內文。

## 標題

一般文字。**粗體**、[連結](https://example.com) 之類。

![圖片說明](/images/photo.jpg)
```

4. **Commit changes** → 1～2 分鐘後會自動出現在首頁部落格欄和文章列表中

- 加了 `pinned: true` 的文章 → 在首頁以「推薦」大圖顯示（最多 2 篇）
- 其他文章 → 首頁依新舊顯示最多 4 篇，全部文章在 `/blog/`
- 圖片請建一個 `images` 資料夾上傳到那裡
- 草稿放在 `_drafts` 資料夾裡就不會發布

### 把文章設為不公開

在文章開頭（`---` 之間）加一行就好。刪掉這一行就會重新公開。

```markdown
published: false
```

設為不公開的文章，在文章頁、列表、首頁、通知、RSS 中都不會出現。
※ 儲存庫本身是公開的，所以檔案內容在 GitHub 上還是看得到。

## 通知（名字下方的跑馬燈）

會自動顯示的內容（依新舊最多輪播 3 則）：

- 發布文章 → 「「◯◯」をupしました」（發布了「◯◯」）
- 替 `projects` 填上 `date` → 已完成時顯示「新專案「◯◯」完成了」，製作中時顯示「開始製作「◯◯」」

想顯示其他內容時，加到 `data/news.json`。

什麼都沒有時，通知欄會整個消失。

## 專案

在 `data/projects.json` 中管理。

- 項目：名稱、狀態、公開/不公開、日期、說明、標籤、版本、圖片、儲存庫、下載網址和按鈕文字、介紹頁

## 社群帳號

只要在 `data.js` 的 `links` 裡填上網址 / ID 就好。留空也會顯示名字，點一下可以複製名字。

## 多語言支援

網站可以用 **日文・English・简体中文・繁體中文・한국어** 顯示。

- 語言依「網址中的 `?lang=en` 等」→「上次選擇的語言」→「瀏覽器語言」的順序自動決定。
- 可以用右上角的 🌐 按鈕（或控制中心）切換。
- 翻譯都集中在 `i18n.js` 裡。
  - 介面文字 → `T`
  - `data.js` 中的手機備註、一句話點評，以及 `projects.json` 中的說明 → `DATA`（以日文原文作為鍵，寫上譯文）
- **沒有寫翻譯的文字會直接顯示日文**，所以更新了 `data.js` 卻忘了加翻譯，也不會出錯。
- 部落格內文維持日文（用日文以外的語言瀏覽時，會顯示「用 Google 翻譯閱讀」的連結）。
