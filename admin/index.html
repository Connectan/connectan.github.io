このブラウザで管理画面を使う

GitHub のトークンを入れてください。トークンは PIN で暗号化してこのブラウザの中だけに保存します（GitHub やほかの端末には置きません）。次からは PIN だけで開けます。トークンを持っていない人は開けません。

  1. トークン作成ページを開く（Fine-grained token）
  2. Resource owner が Connectan になっているか確認
  3. Expiration：1年くらいがおすすめ（切れたら「設定」から更新できます）
  4. Repository access → Only select repositories → connectan.github.io だけ選ぶ
  5. Permissions → Repository permissions → Contents を Read and write に
    ← ここが「Read-only」や未設定だと 403 になります
  6. Generate token → 出てきた github_pat_… を下に貼る

✅ 前の管理画面で使っていたトークンが、このブラウザに残っていたので入れておきました。PIN を決めるだけで OK です（暗号化して保存し直します）。

セキュリティについて
  • トークンは AES-256-GCM で暗号化してこのブラウザの中だけに保存。GitHub（公開リポジトリ）には何も置きません。
  • 新しい端末では、トークンを入れないと絶対に開けません。
  • PIN を10回間違えると、この端末からトークンを消します。
