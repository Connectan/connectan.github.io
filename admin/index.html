管理画面にログイン

GitHub のトークンでログインします。トークンはこのブラウザの中にだけ保存されます。

  1. トークン作成ページを開く
  2. Token name は何でもOK、Expiration は好みで（No expiration も可）
  3. Repository access → Only select repositories → connectan.github.io
  4. Permissions → Repository permissions → Contents を Read and write
  5. Generate token → 出てきた github_pat_… をコピーして下に貼る
