## 파일 구성

| 파일 | 내용 | 자주 수정? |
|---|---|---|
| `data.js` | 메인 페이지 내용(이름·SNS·폰·프로젝트) | ◎ |
| `_posts/` | 블로그 글(1글 = 1파일) | ◎ |
| `index.html` / `home.js` | 메인 페이지 뼈대 | 가끔 |
| `blog/index.html` | 글 목록 페이지 | 거의 안 건드림 |
| `_layouts/post.html` | 글 페이지 디자인 | 거의 안 건드림 |
| `style.css` / `common.js` | 디자인과 애니메이션(모든 페이지 공통) | 거의 안 건드림 |
| `i18n.js` | 다국어 번역 사전(일본어·English·简体中文·繁體中文·한국어) | 가끔 |
| `posts.json` | 글 목록 데이터(자동 생성되니 건드리지 않음) | × |
| `_config.yml` | 블로그 설정 | × |

## 블로그 글 쓰는 법

1. `_posts` 폴더를 열고 **Add file → Create new file**
2. 파일명을 `연-월-일-영어제목.md`로 합니다
   예: `2026-11-25-magic-v3-review.md`
   (영어 부분이 URL이 됨 → `/blog/2026/11/25/magic-v3-review/`)
3. 맨 위에 아래 내용을 쓰고, 그 아래에 본문을 Markdown으로 씁니다

```markdown
---
title: Magic V3 を3ヶ月使った感想
tags: [Honor, 折りたたみ, レビュー]
pinned: true        # 추천에 띄우고 싶을 때만. 필요 없으면 이 줄을 통째로 삭제
cover: /images/magic-v3.jpg   # 대표 이미지(없어도 OK)
---

여기서부터 본문.

## 제목

일반 문장. **굵게**라든가 [링크](https://example.com)라든가.

![이미지 설명](/images/photo.jpg)
```

4. **Commit changes** → 1~2분이면 메인 페이지 블로그란과 글 목록에 자동으로 나옵니다

- `pinned: true`를 붙인 글 → 메인 페이지에 크게 "추천"으로 표시(최대 2개)
- 그 외 → 최신순으로 4개까지 메인에 표시, 전체는 `/blog/`에
- 이미지는 `images` 폴더를 만들어서 거기에 업로드
- 초안은 `_drafts` 폴더에 두면 공개되지 않습니다

### 글을 비공개로 하기

글 맨 위(`---` 사이)에 한 줄만 추가하면 됩니다. 지우면 다시 공개됩니다.

```markdown
published: false
```

비공개로 한 글은 글 페이지·목록·메인·알림·RSS 어디에도 나오지 않습니다.
※ 저장소 자체는 공개라서 파일 내용은 GitHub에서 보입니다.

## 알림(이름 아래의 알림)

자동으로 나오는 것(최신순으로 최대 3개가 흘러감):

- 글을 공개 → "「◯◯」をupしました"(「◯◯」을(를) 올렸습니다)
- `projects`에 `date`를 넣기 → 완성이면 "새 프로젝트 「◯◯」 완성", 제작 중이면 "「◯◯」 제작을 시작했습니다"

그 외의 것을 띄우고 싶을 때는 `data/news.json`에 추가합니다.

아무것도 없으면 알림란째로 사라집니다.

## 프로젝트

`data/projects.json`에서 관리.

- 항목: 이름·상태·공개/비공개·날짜·설명·태그·버전·이미지·저장소·다운로드 URL과 버튼 문구·소개 페이지

## SNS

`data.js`의 `links`에 URL / ID를 넣기만 하면 됩니다. 비워 둬도 이름은 표시되고, 탭하면 이름을 복사할 수 있습니다.

## 다국어 지원

사이트는 **일본어·English·简体中文·繁體中文·한국어** 로 볼 수 있습니다.

- 언어는 "URL의 `?lang=en` 등" → "지난번에 고른 언어" → "브라우저 언어" 순서로 자동으로 정해집니다.
- 오른쪽 위의 🌐 버튼(또는 컨트롤 센터)에서 바꿀 수 있습니다.
- 번역은 `i18n.js`에 모여 있습니다.
  - 화면 문구 → `T`
  - `data.js`의 폰 메모·한마디와 `projects.json`의 설명 → `DATA`(일본어 원문을 그대로 키로 하고 번역을 씀)
- **번역을 쓰지 않은 문장은 일본어 그대로 나오기** 때문에, `data.js`를 수정하고 번역 추가를 깜빡해도 깨지지 않습니다.
- 블로그 글 본문은 일본어 그대로입니다(일본어 이외의 언어로 보는 사람에게는 "Google 번역으로 읽기" 링크가 나옵니다).
